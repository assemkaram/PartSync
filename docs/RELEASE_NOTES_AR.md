# RIGPILOT PC Builder — ملاحظات الإصدار والإصلاحات

## إصلاحات الصفحات والتحميل

- إصلاح التعامل مع أخطاء تحميل الصفحات المقسمة ديناميكيًا، مع إعادة محاولة محدودة ومنع حلقة إعادة تحميل لا نهائية.
- إضافة حدود أخطاء على مستوى الصفحة حتى لا يؤدي تعطل صفحة واحدة إلى تعطيل التطبيق بالكامل.
- جعل صفحة HTML الرئيسية غير قابلة للتخزين طويل المدى، مع السماح بتخزين ملفات الأصول ذات الأسماء المعرّفة بإصدار طويل.
- تحديث قواعد Vercel وNetlify وApache حتى لا تتحول طلبات ملفات JavaScript أو CSS أو JSON أو الصور المفقودة إلى `index.html`؛ الملفات الثابتة المفقودة ترجع 404 حقيقية.
- تحسين بدء صفحات البحث والباني باستخدام بيانات الكتالوج الأولية، ثم تحديثها في الخلفية عند توفر الشبكة.

## إصلاحات الأسعار والتجميعات

- توحيد التحقق من السعر في البحث والمقارنة والباني والتجميعات الجاهزة ومساعد الذكاء الاصطناعي والحفظ.
- لا يُقبل سعر أقل من 100 جنيه مصري أو سعر بعملة غير EGP كسعر مكوّن صالح.
- لا يتقدم عرض قديم على عرض أحدث لمجرد أن سعره أقل؛ تُراعى حالة المخزون وحداثة السعر قبل المقارنة السعرية.
- إذا كان سعر أي قطعة غير متاح، لا يُعرض المجموع الجزئي على أنه إجمالي التجميعة، ولا يُستخدم لتقييم القيمة أو اقتراح ترقية مالية.
- حساب استهلاك الطاقة منفصل عن صلاحية السعر، مع عدم عرض تقدير طاقة جزئي إذا كانت قطع محفوظة مفقودة.
- التحقق من أسعار القطع التاريخية عند فتح التجميعات المحفوظة بدل الاعتماد على الإجمالي القديم المخزن فقط.
- إصلاح صفحة تفاصيل التجميعة لتفتح التجميعات المحفوظة من قاعدة البيانات، وتعرض الكميات والقطع المفقودة وحالة الأسعار.
- عند غياب قطعة أو سعر أو بيانات موثوقة، تظهر حالة واضحة بدل اختراع سعر أو إجمالي.

## ملاحظة مهمة عن حداثة الأسعار

ملف الأسعار المرفق داخل المشروع تم التقاطه بتاريخ **3 نوفمبر 2026**. لذلك لا يُعامل باعتباره أسعارًا لحظية في **25 نوفمبر 2026**. يعرض التطبيق تحذير حداثة السعر عند تجاوز 48 ساعة، ويستبعد 170 سجلًا تجريبيًا/غير صالح بسعر 1 جنيه مصري من حسابات الأسعار.

للحصول على أسعار فعلية حديثة، يجب تشغيل/تحديث مصادر المتاجر أو مزامنة الكتالوج من قاعدة البيانات. إصلاحات الكود تمنع الأسعار غير الموثوقة من تلويث الإجماليات، لكنها لا تُنشئ عروض متاجر جديدة من تلقاء نفسها.

## مطلوب قبل استخدام التجميعات المحفوظة على قاعدة البيانات

تأكد من تطبيق الترحيل التالي على مشروع Supabase المتصل:

`supabase/migrations/016_retailer_build_item_snapshots.sql`

هذا الترحيل يضيف مفتاح القطعة ونسخة مواصفاتها وسعرها المحفوظ، حتى تستمر التجميعات القديمة والجديدة في الفتح بعد تغير بيانات الكتالوج. لم يتم تعديل قاعدة بياناتك البعيدة من داخل هذه الحزمة.

## أوامر التشغيل

```bash
pnpm install --frozen-lockfile
pnpm dev
```

وبعد ضبط متغيرات البيئة وربط Supabase وتطبيق الترحيل المطلوب:

```bash
pnpm build
pnpm preview
```
