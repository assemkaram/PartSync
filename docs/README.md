# دليل التوثيق

هذه هي المراجع الحالية المعتمدة:

- `ARCHITECTURE.md`: حدود client/server وتدفق الطلبات.
- `PROJECT_STRUCTURE_AR.md`: خريطة المجلدات ومسارات التشغيل.
- `DATABASE.md`: جداول Supabase والمigrations وRLS.
- `COMPATIBILITY_RULES.md`: قواعد توافق مكونات PC.
- `RETAILER_STRATEGY.md`: مصادر المتاجر وتحديث الأسعار.
- `AI_ARCHITECTURE.md`: تدفق AI والموديلات والحصص.
- `JAVASCRIPT_GUIDE_AR.md`: أسلوب JavaScript وتنظيمه.
- `RELEASE_NOTES_AR.md`: ملاحظات النسخة الحالية.

تمت إزالة الوثائق القديمة المكررة أو المنتهية من الحزمة؛ هذه القائمة هي مراجع التشغيل الحالية.

- `SCRIPTS_AR.md` — شرح أوامر الفحص والاختبارات والسكربتات التي تم الاحتفاظ بها.
